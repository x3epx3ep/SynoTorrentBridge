# SynoTorrentBridge

Приложение для Windows, которое перехватывает **magnet-ссылки** и **.torrent-файлы**
и отправляет их в **Synology Download Station**, позволяя выбрать конечную папку на NAS
и файлы внутри раздачи.

## Возможности

- Клик по magnet-ссылке в браузере → открывается окно приложения вместо торрент-клиента.
- Двойной клик по `.torrent` файлу → то же самое.
- Выбор **папки назначения** на NAS: дерево папок (через FileStation), создание новой папки,
  история последних папок.
- Выбор **файлов внутри раздачи до старта закачки** — тот же механизм, что в мобильном
  DS get, с применением выбора на стороне NAS:
  - для `.torrent` файл сначала уходит на NAS как «отложенный список» (`create_list`),
    задача создаётся вызовом `Task.List.Polling download` с параметром `selected` —
    NAS сам ставит `wanted` только выбранным файлам **до старта закачки**, гонки нет;
  - для magnet-ссылок NAS игнорирует `create_list` и создаёт задачу сразу, поэтому
    приложение ждёт метаданные, **мгновенно снимает `wanted` со всех файлов**
    (закачка замирает, ничего не скачивается), показывает диалог выбора и возвращает
    `wanted` только выбранным; отмена удаляет задачу;
  - если NAS не поддерживает эти вызовы, приложение автоматически откатывается
    на старую схему (`SYNO.DownloadStation2.Task.BT.File`).
- Поиск и фильтры в списке файлов: поиск по имени, «Все/Ничего», «Только видео», «Без субтитров».
- Проверка дубликатов: если задача с таким именем уже есть в Download Station — предупреждение.
- Уведомления о завершении закачек: фоновый монитор (автозагрузка, включается в настройках)
  показывает тост, когда задача завершается.
- Приложение видно в «Параметры → Приложения → Установленные приложения»: удаление штатное,
  `--uninstall` снимает перехват, автозагрузку, настройки и сам exe.
- Пароль хранится в зашифрованном виде (Windows DPAPI) в `%APPDATA%\SynoTorrentBridge\config.json`.
- Поддержка HTTPS и двухфакторной аутентификации — если на NAS включена 2FA,
  приложение само попросит одноразовый код **один раз**: дальше компьютер
  запоминается как доверенное устройство (device token в `config.json`),
  и код больше не требуется, пока вы не отзовёте устройство в DSM
  (Панель управления → Безопасность → Учётная запись → Доверенные устройства).
- Автоопределение DSM 6 / DSM 7 (Download Station / Download Station 2).

## Установка

1. Скопируйте `dist\SynoTorrentBridge.exe` в постоянную папку, например
   `C:\Tools\SynoTorrentBridge\` (после регистрации перехвата файл нельзя перемещать —
   иначе перерегистрируйте).
2. Запустите `SynoTorrentBridge.exe` — откроется окно настроек:
   - адрес NAS (например `192.168.1.10` или `nas.local`), порт (`5000` для HTTP / `5001` для HTTPS);
   - логин и пароль пользователя DSM (должен иметь права на Download Station);
   - при включённой 2FA — текущий одноразовый код (понадобится заново, когда сессия истечёт).
3. Нажмите **«Проверить подключение»** — приложение покажет версию API и доступность выбора файлов.
4. Нажмите **«Сохранить»**, затем **«Включить»** в блоке «Перехват magnet-ссылок и .torrent».

Всё, теперь magnet-ссылки и .torrent-файлы открываются в SynoTorrentBridge.

> Перехват регистрируется в ветке `HKCU\Software\Classes` — права администратора не нужны.
> Если другой торрент-клиент уже назначен на magnet, Windows может один раз спросить,
> каким приложением открывать ссылку — выберите SynoTorrentBridge и «Всегда».

## Использование

- **.torrent файл**: откроется список файлов с галочками — снимите лишние,
  выберите папку назначения, нажмите **«Скачать»**. Невыбранные файлы помечаются
  в Download Station как `skip`.
- **magnet-ссылка**: выберите папку и оставьте галочку «Выбрать файлы после получения
  метаданных» — после того как NAS получит список файлов от пиров (обычно секунды),
  появится окно выбора файлов. Если снять галочку — скачается всё.

## Командная строка

```
SynoTorrentBridge.exe "magnet:?xt=..."     добавить magnet
SynoTorrentBridge.exe "file.torrent"       добавить торрент-файл
SynoTorrentBridge.exe --settings           окно настроек
SynoTorrentBridge.exe --register           включить перехват
SynoTorrentBridge.exe --unregister         выключить перехват
```

## Диагностика

Лог пишется в `%APPDATA%\SynoTorrentBridge\bridge.log` — если что-то не работает,
пришлите этот файл.

## Известные ограничения

- Выбор файлов работает только на DSM 6.1+/7 (API `SYNO.DownloadStation2.Task.BT.File`).
  На старом DSM 6 торрент добавляется целиком.
- Выбор файлов через `BT.File set` (параметры `index` + `wanted`) — недокументированный
  вызов, проверен на Download Station 4.1.2 / DSM 7. Если на вашей версии он изменится,
  выбор файлов не применится (торрент скачается целиком), а в лог попадёт ошибка.
- Между добавлением задачи и применением выбора файлов NAS может успеть скачать
  несколько килобайт из исключённых файлов — это неизбежно для такого подхода.
