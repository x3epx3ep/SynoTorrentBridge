# SynoTorrentBridge

Приложение для Windows, которое перехватывает **magnet-ссылки** и **.torrent-файлы**
и отправляет их в **Synology Download Station**, позволяя выбрать конечную папку на NAS
и файлы внутри раздачи — **до старта закачки**.

[English version](README.md) · [История изменений](CHANGELOG.md)

## Возможности

- Клик по magnet-ссылке в браузере → открывается окно приложения вместо торрент-клиента.
  Двойной клик по `.torrent` файлу → то же самое.
- Выбор **папки назначения** на NAS: дерево папок (через FileStation), создание новой папки,
  история последних папок. Если введённой папки нет — приложение предложит её создать.
- Выбор **файлов внутри раздачи до старта закачки** — тот же механизм, что в мобильном DS get:
  - для `.torrent` файл сначала уходит на NAS как «отложенный список» (`create_list`),
    задача создаётся вызовом `Task.List.Polling download` с параметром `selected` —
    NAS сам ставит `wanted` только выбранным файлам **до старта закачки**, гонки нет;
  - для magnet-ссылок NAS игнорирует `create_list` и создаёт задачу сразу, поэтому
    приложение ждёт метаданные, **мгновенно снимает `wanted` со всех файлов, кроме
    одного самого маленького** (закачка почти замирает; снять со всех нельзя — Download
    Station тогда застревает в «Проверке»), показывает диалог выбора и оставляет `wanted`
    только выбранным; отмена удаляет задачу;
  - если NAS не поддерживает эти вызовы, приложение откатывается на
    `SYNO.DownloadStation2.Task.BT.File` (снятие `wanted` после создания задачи).
- Поиск и фильтры в списке файлов: поиск по имени, «Все/Ничего», «Только видео», «Без субтитров».
  Отправить задачу без единого выбранного файла нельзя — для отказа есть «Отмена».
- Проверка дубликатов: по info-hash (для magnet-задач) или точному имени задачи.
  Найденную «похожую» задачу приложение никогда не меняет и не удаляет.
- Уведомления о завершении закачек: фоновый монитор (автозагрузка, включается в настройках)
  показывает уведомление, когда задача докачалась — в том числе если она сразу ушла на раздачу.
- Видно в «Параметры → Приложения → Установленные приложения»: удаление штатное.
  `--uninstall` останавливает монитор, снимает перехват (возвращая прежний торрент-клиент,
  если он был), автозагрузку, по желанию — настройки, и удаляет сам exe.
- Пароль хранится в зашифрованном виде (Windows DPAPI) в `%APPDATA%\SynoTorrentBridge\config.json`.
- HTTPS по умолчанию и двухфакторная аутентификация: если на NAS включена 2FA,
  приложение спросит одноразовый код **один раз** — дальше компьютер запоминается
  как доверенное устройство, пока вы не отзовёте его в DSM
  (Панель управления → Безопасность → Учётная запись → Доверенные устройства).
- Автоопределение DSM 6 / DSM 7 (Download Station / Download Station 2).
- Автообновление с GitHub Releases по одной кнопке: скачанный файл проверяется по
  контрольной сумме SHA-256, которую публикует GitHub; обновление проходит даже при
  запущенном мониторе (он перезапускается).
- Если exe переместили или скачали заново под именем `SynoTorrentBridge (2).exe`,
  при запуске перехват, автозагрузка и запись в «Приложениях» сами переводятся на него.

## Установка

1. Скачайте `SynoTorrentBridge.exe` со страницы [Releases](../../releases) и положите
   в постоянную папку, например `C:\Tools\SynoTorrentBridge\`.
2. Запустите его двойным щелчком — откроется окно настроек:
   - адрес NAS (например `192.168.1.10`, `nas.local` или `https://nas.example.ru:5001`);
   - порт: `5001` для HTTPS (по умолчанию) или `5000` для HTTP — меняется вместе с галочкой HTTPS;
   - «Проверять SSL-сертификат» снимайте, только если у DSM самоподписанный сертификат;
   - логин и пароль пользователя DSM с правами на Download Station (и FileStation — для выбора папок).
3. Нажмите **«Проверить подключение»** — при включённой 2FA появится окно для кода.
4. Нажмите **«Сохранить»**, затем **«Включить»** в блоке «Интеграция с Windows».

> Перехват регистрируется в `HKCU\Software\Classes` — права администратора не нужны.
> Если другой торрент-клиент уже назначен на magnet, Windows может один раз спросить,
> каким приложением открывать ссылку — выберите SynoTorrentBridge и «Всегда».

> При первом запуске Windows может показать предупреждение SmartScreen: exe не подписан
> цифровой подписью. Сверьте SHA-256 из описания релиза:
> `Get-FileHash SynoTorrentBridge.exe` в PowerShell.

## Использование

- **.torrent файл**: откроется список файлов с галочками — снимите лишние,
  выберите папку назначения, нажмите **«Скачать»**. Задача создаётся сразу только
  с выбранными файлами.
- **magnet-ссылка**: выберите папку и оставьте галочку «Выбрать файлы после получения
  метаданных» — когда NAS получит список файлов от пиров (обычно секунды), появится окно
  выбора. Если снять галочку — скачается всё.

## Командная строка

```
SynoTorrentBridge.exe "magnet:?xt=..."     добавить magnet
SynoTorrentBridge.exe "file.torrent"       добавить торрент-файл
SynoTorrentBridge.exe --settings           окно настроек
SynoTorrentBridge.exe --register           включить перехват
SynoTorrentBridge.exe --unregister         выключить перехват (вернуть прежний клиент)
SynoTorrentBridge.exe --uninstall          удалить программу
```

## Диагностика

Журнал — `%APPDATA%\SynoTorrentBridge\bridge.log` (при 1 МБ уходит в `bridge.log.1`,
хранятся 3 старые копии; паролей в журнале нет). Если что-то не работает, пришлите этот файл.

## Безопасность

- Пароль зашифрован DPAPI — расшифровать его может только ваш пользователь на этом компьютере.
- Вход выполняется POST-запросом: пароль не попадает в адресную строку и журналы веб-сервера.
  Используйте HTTPS, чтобы он не шёл по сети открытым текстом.
- Обновление устанавливается, только если SHA-256 файла совпадает с опубликованной на GitHub.

## Сборка из исходников

```
python -m pip install pyinstaller pillow
build_exe.bat
```

Результат — `dist\SynoTorrentBridge.exe` с версией в свойствах файла; скрипт выводит его SHA-256.
Запуск без сборки: `python main.py` (нужен только стандартный Python 3.10+).

## Известные ограничения

- Выбор файлов работает только на DSM 7 (Download Station 2). На DSM 6 торрент
  добавляется целиком (приложение предупредит).
- Вызовы `Task.List.Polling` и `Task.BT.File set` недокументированы; проверены на
  Download Station 4.x / DSM 7. Если на вашей версии они изменятся, приложение
  перейдёт на запасной путь, а в журнал попадёт ошибка.
- Для magnet-ссылок между созданием задачи и снятием `wanted` NAS может успеть
  скачать несколько килобайт, а пока открыто окно выбора, качается один самый маленький
  файл раздачи (и куски соседних файлов на границах частей) — это неизбежно, пока NAS
  не умеет «отложенный список» для magnet.
- exe не подписан цифровой подписью (нужен платный сертификат), отсюда предупреждение SmartScreen.
