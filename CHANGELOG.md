# История изменений

## 1.5.0 — 2026-11-15

Исправления по итогам ревью.

### Исправлено
- **Обновление при запущенном мониторе.** Монитор работает из того же exe, и раньше
  замена файла падала, оставляя программу не обновлённой и не запущенной. Теперь
  обновление останавливает монитор, отодвигает старый exe в `*.old` (переименовать
  запущенный файл Windows разрешает), ставит новый и перезапускает программу и монитор.
- **Удаление не удаляло exe.** `timeout` без консоли завершался сразу, а `del`
  запускался, пока процесс ещё жив. Теперь файл удаляет скрытый PowerShell после
  выхода процессов программы; монитор перед удалением останавливается.
- **Уведомления о завершении.** Учитывается статус 8 («завершена, раздаётся»):
  раньше задачи, ушедшие на раздачу, уведомления не давали. Монитор видит все задачи
  (постранично), а не первые 100, и запускается в единственном экземпляре.
- **Поиск задачи мог задеть чужую.** Совпадение «по подстроке имени» убрано.
  Дубликаты определяются по info-hash (magnet) или точному имени и только для
  предупреждения. Если NAS не вернул id новой задачи, она ищется только среди задач,
  появившихся после отправки, — старая задача с похожим именем больше не может
  быть изменена или удалена по «Отмене».
- Тайм-аут при чтении ответа NAS теперь даёт понятную ошибку на русском и
  включает запасные пути, а не обрывает поток.
- Нельзя отправить задачу без единого выбранного файла.
- Несуществующая папка назначения проверяется заранее; приложение предлагает её создать.
- Отмена и закрытие окна больше не «замораживают» его при недоступном NAS.
- Выключение перехвата возвращает прежний торрент-клиент и не удаляет чужие записи
  `.torrent\OpenWithProgids`.

### Безопасность
- Обновление проверяется по SHA-256, который GitHub публикует для файла релиза, и по размеру.
- Вход в DSM — POST-запросом: пароль не попадает в строку запроса.
- По умолчанию для новых настроек — HTTPS, порт 5001; порт следует за галочкой HTTPS.

### Прочее
- Журнал ротируется при 1 МБ (3 копии), длинные списки в нём сокращаются.
- Пути перехвата, автозагрузки и записи «Приложения» сами переводятся на exe,
  если его переместили или скачали заново.
- Хвосты обновления (`*.old`, временный exe) удаляются при запуске.
- Версия видна в свойствах exe.
- Новые тесты: монитор, межпроцессная остановка, замена занятого exe, реестр,
  удаление, журнал, сценарий окна добавления, проверка на живом NAS.
- Документация обновлена (устаревшие разделы README исправлены).
